📌 Overview

This project implements a Linear Regression model to predict house prices based on numerical housing and socio-economic features.
The objective is to understand how different factors affect house prices and evaluate the performance of a regression model.

📊 Dataset

The dataset contains the following features:

Avg. Area Income

Avg. Area House Age

Avg. Area Number of Rooms

Avg. Area Number of Bedrooms

Area Population

Target Variable:

Price

The Address column was removed because it contains non-numerical values and cannot be used in Linear Regression.

🔍 Methodology

Load and explore the dataset

Remove non-numeric columns

Split data into training and testing sets

Train a Linear Regression model

Make predictions on test data

Visualize results

📈 Model Evaluation

The model was evaluated using:

Mean Absolute Error (MAE)

Root Mean Squared Error (RMSE)

R² Score

These metrics help measure prediction accuracy and overall model performance.
